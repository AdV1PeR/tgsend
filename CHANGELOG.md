# Changelog

## 1.3 — 2026-11-04

- конфиг по умолчанию `~/.config/tgsend/config`, переопределяется `TG_CONF`;
  креды больше не хардкодятся в скрипте
- проверка токена через `getMe` вместо `getUpdates` (совместимо с вебхуками)
- таймауты и ретраи curl, обработка `429` с паузой `retry_after`
- длинные сообщения режутся на части по 4000 символов, по границам строк
- `MarkdownV2` и `HTML` включаются флагами `-M` / `-H`; по умолчанию — plain text
- новые флаги: `-n/--dry-run`, `-s/--silent`, `-t/--topic`, `-C/--chat`
- строгая проверка файла: существует, обычный файл, читается, не пустой, в лимите
- лимит подписи 1024 символа проверяется до отправки
- ротация лога на 1 МБ; в лог не попадают токен и `chat_id`
- исправлено: смешивание `-d` и `-F` в одном запросе приводило к пустому телу
- исправлено: `set -e` завершал скрипт на безобидных проверках флагов
- исправлено: `-H` конфликтовал сам с собой
- внятные ошибки при пустом ответе API, коды возврата, `shellcheck` чист

## 1.2 — 2026-11-04

- исправлено падение на markdown-разметке и на отсутствующем аргументе
- несуществующий файл больше не уходит как текст

- таймауты, ретраи, обработка `429`
- флаг подписи `-c`, тихий режим `-q`, ротация лога
- Termux-совместимый шебанг
